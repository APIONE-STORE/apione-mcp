# Security policy

Report vulnerabilities privately using GitHub private vulnerability reporting (Security tab, Report a vulnerability) on this repository. Do not open a public issue for a security problem.

Please include the affected endpoint or tool, steps to reproduce and the impact. We aim to acknowledge reports within 3 business days.

Never post API keys in issues or pull requests. If a key has been exposed, rotate it in your ApiOne dashboard immediately.

This repository contains documentation and examples only. The hosted service is out of scope for source-level reports, but its public endpoints are in scope for responsible disclosure.
